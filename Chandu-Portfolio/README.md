# Mogilicharla Chandu — Hackathon Portfolio

Premium dark/futuristic React portfolio built for hackathon presentation.

## Run locally
1. Install Node.js 18+.
2. Extract this folder.
3. Open a terminal in the folder.
4. Run:
   npm install
   npm run dev
5. Open the Vite URL shown in the terminal.

## Build for deployment
npm run build

Upload the generated `dist` folder to Netlify, Vercel, or another static host.

## Included
- Responsive React single-page portfolio
- Animated hero, glowing orbit, hover effects and mobile navigation
- Your supplied portrait in `public/chandu.jpg`
- Resume in `public/Chandu-Resume.pdf`
- AI Prompt Engineer positioning
- Skills, projects, experience, education, achievements and contact sections

Note: The project card imagery uses remote Unsplash URLs; replace them with local screenshots of your real projects before the final hackathon submission for faster loading and stronger authenticity.
